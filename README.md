# Applied Quantum Cybersecurity in Maryland
**Team:** IQM Market Research (Valentina Santos & Nebiyu Nebiyeleul)

## Project Overview
This project maps the distribution of applied quantum research across the DMV/Maryland academic and national lab ecosystem to evaluate technology readiness.

## Repository Structure
- `/data`: Contains raw datasets and processed CSVs.
- `/scripts`: Python scripts for data cleaning and network building.
- `/notebooks`: Jupyter notebooks for exploratory data analysis.
- `/visualizations`: Generated relational ecosystem network graphs.

## Setup Instructions
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
